# 📊 HR Analysis

## 📌 Overview
A data analysis project that explores employee information to uncover workforce trends, employee performance, salary distribution, and attrition insights through data visualization.

## ✨ Features
- Employee analysis
- Attrition analysis
- Salary distribution
- Department insights
- Interactive visualizations

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit

## 📈 Key Insights
- Employee attrition
- Department performance
- Salary analysis
- Workforce statistics
